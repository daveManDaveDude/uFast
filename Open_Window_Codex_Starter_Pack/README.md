# Open Window Codex Starter Pack

This folder contains the product context needed to begin the MVP. Treat these files as living repository documentation.

- `PRODUCT.md` — promise, goal, user, principles and measures.
- `MVP_SCOPE.md` — in/out boundary and build sequence.
- `DOMAIN_RULES.md` — shared terms and numbered behavioural rules.
- `BACKLOG.md` — ordered starter backlog and example ready stories.
- `READY_STORIES.md` — the first two user-facing stories in implementation-ready form.
- `STORY_TEMPLATE.md` — required format and readiness checks.
- `DECISIONS.md` — choices that must be settled or recorded.
- `AGENTS.template.md` — starting repository guidance for Codex; rename to `AGENTS.md` and fill in real commands after project creation.

Recommended first product work:

1. Resolve the decisions in `DECISIONS.md`.
2. Create the Xcode repository and complete OW-000.
3. Refine OW-002 and OW-101 against the actual architecture.
4. Give Codex one ready story at a time and require tests plus diff review.
