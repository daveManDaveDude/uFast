# Slice 3.5 concept boards

These generated boards are journey and hierarchy references for OW-350. They
are not production assets and must not be cropped or shipped in uFast.

All three were generated with the built-in image-generation tool as realistic
native-iOS `ui-mockup` boards. Each prompt required the established warm ivory,
evergreen, sage, sky and restrained apricot palette; eight journey states;
light plus representative dark appearance; narrow-phone composition;
structured accessibility alternatives; en_GB/DST examples; and explicit
exclusion of inference, scoring, streaks, health claims and new persistence.

## Family A — Calendar + day rail

Selected path: `family-a-calendar-day-rail/journey-board-v2.png`

Prompt signature: month/date navigator plus selected-day variable-length local
time rail; clipped overnight segments with continuation markers; native detail
sheet; shared Catch-up day rail; lane allocation; semantic list fallback.

## Family B — Seven-day columns

Selected path: `family-b-seven-day-columns/journey-board-v2.png`

Prompt signature: seven adjacent day columns sharing a time-axis grammar;
linked overnight continuity between column edges; selected-column expansion;
week-based Catch up; grouped-list accessibility alternative.

## Family C — Temporal ribbon

Selected path: `family-c-temporal-ribbon/journey-board-v2.png`

Prompt signature: horizontally scrolling night-centred continuous interval
ribbon with compact date chips; evening–midnight–morning in one band; ribbon
reused for repair and proposal review; chronological semantic list alternative.

The complete research, trade-offs and recommendation are in
`../../SLICE_3_5_HISTORY_UX_STORIES.md`.

The unversioned `journey-board.png` files are retained as first-pass drafts.
The v2 boards remove generator artifacts that implied invented navigation,
notes or inaccurate per-date DST claims.
