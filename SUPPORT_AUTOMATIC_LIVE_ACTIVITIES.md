# uFast support — automatic Live Activities release

uFast is a free, local-only manual tracker for iPhone running iOS 26.0 or later.

Automatic Live Activities are optional. After you successfully start a fast,
uFast offers once to show elapsed time, goal progress and target on the Lock
Screen and Dynamic Island. Each activity lasts up to eight hours. If the fast is
still active, a new one can be requested only when you later open or foreground
uFast. Settings can turn the feature off, and Today offers **Hide for this
fast**. The local fast and the user-added Lock Screen widget continue if an
activity is unavailable, dismissed or ends.

No account, notification permission, server, APNs or network connection is
required. Records and Live Activity preference/lifecycle metadata stay on the
iPhone.

For private support, email <ufast.app@gmail.com>. For public bug reports, visit
<https://github.com/daveManDaveDude/uFast/issues>. Please do not include
sensitive health information in a public issue unless it is necessary to explain
the problem.
